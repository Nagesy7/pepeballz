# PepeNugs: Cate's Fury

An Inu pack adventure: every villager is an Inu, the enemies are Cate the Catnip Queen (an upright grey tabby with a crown and cape) and her ginger tabby Catnip Kits, and cosmetics tie into $KIBBLE.

Display title comes from `src/config.js` (`GAME_TITLE`). The repo, URL (pepeballz.vercel.app), save keys and kibble-pay game id stay `pepeballz`.

This is an original top-down action RPG built with vanilla JS and canvas. It has no frameworks and no build step.
- **Controls:** WASD/arrows to move, J/Z to attack (3-hit combo) or talk, K/X for Howl Wave, hold L/C to rest (recover energy), Space/Shift to dash, Q/V to Unleash, Enter for the menu, M to mute. Touch devices get a thumb stick on the left and buttons on the right.
- **Chapter 1:** Pawpaw Village, Whisker Woods and Fang Peak. The village pond has run dry: collect 5 Pond Lilies (Rose, Sun, Sky, Moss, Dusk), each a permanent buff, beat Cate (she drops the Dusk Lily) and set them in the basin to restore the pond. Pondo the Pond Toad moves back in. No wishes, no summoning.
- **Inu sprites:** ported from Inu Verse (`src/inu/` is a copy, so Inu Verse itself is untouched).
- **Pond Network (`src/kibble.js`):** real kibble-pay wallet by default (Phantom sign-in via `https://kibble-pay.vercel.app/inu-games.js`). $KIBBLE is live (CA `4VE9sy4fEMJdZ6i7MkYPbnqDJd2oqzJQmg44WJ3opump`): Wish Shop / Season purchases and opt-in Legend burns are real and signed in Phantom. Prices are fee-inclusive catalog prices (`pepeballz:<id>`). Owned cosmetics come from `/api/inventory`. Boss Rush / Hunt clears post a wallet-signed score (`/api/game`), and the leaderboards show the real kibble-pay boards and pools. Your Inu Verse Shiba shows in the Pond Network menu. Simulated rivals, payouts, bounties, raids and launches run **only in demo mode (`?demo=1`)**, which uses a separate save. The footer links Terms / Prize Rules. Legacy demo description: It includes a weekly seeded lily hunt, a Cate boss rush, rank-based daily/weekly/monthly pools, holder tiers, the Pond Shop (2% fee in millionths), packs and the Kibble Cup, a co-op raid stub and an Inu Verse export stub. Cosmetics only. Bones never cash out. Plug a real wallet in with `setWallet(adapter)`, using the same shape as `SimWallet`.
- **Tests:** `npm test` runs the headless rules, fee and ranking tests. `npm run e2e -- <url>` runs the Playwright checks; screenshots go to `proof/`.
